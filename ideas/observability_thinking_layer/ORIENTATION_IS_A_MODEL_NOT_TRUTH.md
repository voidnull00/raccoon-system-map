# Orientation Is a Model, Not Truth

## Intent

> **Orientation is not reality. Orientation is the current working model used to interpret reality.**

Treating orientation as truth is a common cause of self-reinforcing loops.

---

## Core Idea

The OODA loop fails most often not at Act — but at Orient.

When orientation is mistaken for objective truth:

- feedback stops updating the model
- it starts defending the model
- the loop confirms itself instead of correcting itself

---

## Layer Map

| Layer        | What it is                   | Failure when treated as truth              |
| ------------ | ---------------------------- | ------------------------------------------ |
| **Observe**  | signals from reality         | cherry-picking signals that fit the model  |
| **Orient**   | current interpretation model | model becomes identity — not revisable     |
| **Decide**   | best move under uncertainty  | commitment to belief instead of best guess |
| **Act**      | generates new signal         | proof-seeking instead of experimenting     |
| **Feedback** | input for model update       | used to validate identity, not revise it   |

---

## Failure Pattern

**Frozen Orient**

```txt
observe → orient (locked) → decide → act
                ↑                      |
                └──────────────────────┘
                    confirms model
                    instead of updating it
```

Frustration, distrust, or narrative harden into 'facts.'

---

## Operator Check

- What am I treating as truth that is only a model?
- What evidence would update this orientation?
- Is this loop reinforcing identity or improving accuracy?
- Am I optimizing to prove something or to increase leverage?

---

## Used For

- diagnosing stuck feedback loops
- separating signal from narrative
- auditing decisions made under false certainty
- restarting a loop that has calcified
