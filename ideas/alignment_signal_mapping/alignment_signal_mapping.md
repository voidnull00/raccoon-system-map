# Alignment Signal Mapping

## Core Idea

Text can be used as a **calibration surface**.

Instead of passively reading or listening, alignment is actively marked using
symbol-based intensity.

The most basic form:

> **exclamation marks (!) represent alignment strength**

The system:

- filters
- marks
- extracts

Transforming passive consumption into active calibration.

---

## Pattern Definition

Each line of text is evaluated and marked based on internal resonance.

```txt
sentence → perceived alignment → symbol intensity
```

---

## Primary Axis

### Alignment → Intensity → Certainty

Symbols:

```txt
(no symbol) → neutral / environmental / not self
!           → recognition / light alignment
!!          → strong alignment
!!!+        → core identity / no doubt
```

Signal layers:

```txt
high !!! → identity / direction
mid  !!  → action / enforcement
low  !   → acknowledgement
none     → environment / context
```

---

## Interpretation

The text becomes:

> **a map of resonance**

Not all lines are equal.

Some are:

- descriptive
- transitional
- environmental

Others are:

- identity anchors
- direction signals
- execution triggers

Alignment tends to cluster around:

- direction
- inevitability
- action

Not around:

- chaos
- destruction
- surface-level intensity

## Relationship to Existing Primitives

### Rangespeaking

Alignment Signal Mapping is a **localized micro-range system**.

Instead of:

```txt
0% → 100%
```

It uses:

```txt
! → !! → !!!
```

**Handoff:** Alignment markers (`!`, `!!`, `!!!`) identify what resonates. Rangespeaking then evaluates how much and relative to what—placing marked signals on a defined axis or spectrum for further decision-making.

---

The pattern helps detect:

> **what remains consistent across different inputs**

High-alignment signals reveal identity stability.

## Why This Works

- **Removes passivity** — you are evaluating yourself through the content, not just consuming it
- **Reduces noise** — only high-signal lines are emphasized
- **Reveals identity** — repeated high-alignment patterns expose what consistently resonates
- **Scales naturally** — works on lyrics, text, ideas, conversations
